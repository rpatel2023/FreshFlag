# Fresh Flag branding

The user-facing product name is **Fresh Flag**.

Use `Fresh Flag` anywhere a person sees or reads the product name, including:

- iOS/Android app display name;
- sign-in, account creation, setup, Settings, and About copy;
- camera-permission copy;
- Discord sender/test-message branding;
- future user-facing notification, help, privacy, and store-listing copy.

Use sentence case for ordinary user actions, for example `Sign in`, `Create account`, `Create invite code`, and `Join household`.

Technical identifiers are intentionally unchanged and may remain unspaced where required or already established:

- Dart package: `freshflag`;
- Flutter class names such as `FreshFlagApp`;
- bundle/application ID: `com.rpatel2023.freshflag`;
- Firebase project ID: `freshflag`;
- GitHub repository: `FreshFlag`;
- source/artifact paths and internal build names such as `FreshFlag.app` and `FreshFlag-unsigned.ipa`.

Do not rename those technical identifiers merely to match display branding; doing so can break Firebase, signing, SideStore updates, imports, or build automation.
